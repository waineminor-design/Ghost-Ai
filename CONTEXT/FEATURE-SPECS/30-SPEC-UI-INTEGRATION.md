Wire spec generation into the Specs tab of the AI sidebar: generate a spec from the canvas, follow its progress, see the project's specs, preview one in a readable window, and download it. Replaces the placeholder card from feature 20. Builds on features 28 (generation) and 29 (storage and routes).

Check the Trigger.dev realtime skill before writing code.

### Generate

- the `Generate spec` button calls `POST /api/ai/spec` with the project id
- disabled when the canvas has no nodes (with a hint "Add something to the canvas first") or while this user's spec run is in progress
- while generating: a status row with a spinner and the current step from the run's metadata
- follow the run with `useRealtimeRun` exactly like feature 27 — mount the follower only once both a run id and a non-empty token exist
- on success: refresh the list and open the new spec's preview; on failure: a short friendly error ("Couldn't generate the spec — try again"), never raw errors

### Spec List

- load `GET /api/projects/[projectId]/specs` when the tab opens
- refresh when the room's `specsUpdatedAt` storage value changes (feature 29), so specs generated by a collaborator appear for everyone
- each row: title, relative date ("5 min ago"), who generated it, and actions: `Preview` and `Download`
- empty state: "No specs yet — generate one from your diagram"

### Preview

- a wide dialog (most of the viewport on desktop, e.g. `max-w-4xl`, tall with its own scroll) built on the existing `EditorDialog` pattern
- loads `GET /api/projects/[projectId]/specs/[specId]` and renders the Markdown with `react-markdown` + `remark-gfm`
- render Markdown only — do not enable raw HTML rendering (no `rehype-raw`), so generated content can't inject HTML or scripts
- readable typography in the dark theme (headings, lists, tables, code blocks) using design tokens
- a `Download` button in the dialog footer

### Download

- links to `GET /api/projects/[projectId]/specs/[specId]/download` so the browser saves the `.md` file

### Rules

- tokens only, existing shadcn components, Lucide icons; accessible buttons and dialog title

### Check when done

    - clicking Generate on a project with a diagram shows progress, then the new spec opens in the preview
    - the preview is wide, scrolls, and renders headings, lists and tables
    - Download saves a `.md` file
    - a collaborator's generated spec appears in the other user's list without a reload
    - Generate is disabled on an empty canvas
    - no "missing access token" errors at any point
    - no TypeScript errors, no lint errors, `npm run build` passes
